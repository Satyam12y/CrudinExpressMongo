# CRUD Contact Management System

A full-stack Contact Management Application built using Node.js, Express.js, MongoDB, Mongoose, EJS, and Bootstrap. This project demonstrates complete CRUD (Create, Read, Update, Delete) operations with a responsive user interface and MongoDB database integration.

## Features

- Add New Contact
- View Contact Details
- Update Existing Contact Information
- Delete Contact Records
- MongoDB Database Integration
- Server-Side Rendering with EJS
- Responsive Bootstrap UI
- Form Handling and Validation
- Dynamic Routing with Express.js

## Installation

### Clone Repository

```bash
git clone https://github.com/Satyam12y/CrudinExpressMongo.git
```

### Navigate to Project Folder

```bash
cd CrudinExpressMongo
```

### Install Dependencies

```bash
npm install
```

### Start MongoDB

Make sure MongoDB is running locally on:

```text
mongodb://127.0.0.1:27017/CrudExpress
```

### Run Application

```bash
npm run dev
```

or

```bash
nodemon index.js
```

### Open Browser

```text
http://localhost:3000
```
